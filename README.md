# Kalkulator Kredit BRI — Unit Sengon

Hitung sendiri angsuran Anda — cepat, mudah, dan bisa dibuka dari HP:

- **KUR** — bunga 6% per tahun
- **Umum** — bunga 22% per tahun

## Fitur
- Perkiraan angsuran per bulan, total bunga, dan total yang dikembalikan
- Rincian angsuran bulanan (angsuran, pokok, bunga, sisa hutang)
- **Simulasi balik**: isi cicilan yang sanggup dibayar → pinjaman maksimal (KUR & Umum)
- **Bagikan ke WhatsApp**: teks ringkasan + gambar rincian siap kirim
- Ekspor ke gambar (PNG) & cetak/PDF
- Buka langsung dari HP tanpa aplikasi tambahan

## Rumus
`A = P x i / (1 - (1+i)^-n)` dengan `i = bunga tahunan / 12`.

Pinjaman maksimal: `P = A x (1 - (1+i)^-n) / i`, dibulatkan ke bawah Rp100.000.

Angka bersifat indikatif — mengikuti perhitungan resmi bank.
